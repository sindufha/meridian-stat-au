Meridian is an offline-first, zero-dependency national statistics portal for Australia featuring official ABS, RBA, DCCEEW, and AIHW indicators across economy, prices, labour, demographics, housing, and clean energy, with interactive SVG charts, a full 8-jurisdiction choropleth map, dual-era population pyramid, inflation and wage benchmark calculators, and client-side CSV/JSON exports.

## Run it

```sh
node serve.ts
# Open http://127.0.0.1:8080 in desktop or mobile Chrome
# Build the submission dossier locally:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
